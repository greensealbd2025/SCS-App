# SCS SUIT — সব অ্যাপ এক জায়গায় (PWA)

## অ্যাপ যোগ / বদল / মুছা (শুধু কোড থেকে)
`apps.js` ফাইল খুলুন। প্রতিটি অ্যাপ এক লাইনে লেখা:
```
{ name: 'SCS Daily Expense', url: 'https://script.google.com/macros/s/.../exec', color: '#dc2626' },
```
- নতুন অ্যাপ যোগ করতে একটা লাইন কপি করে নাম আর লিংক বদলান।
- মুছতে লাইনটা মুছে দিন। সাজানোর ক্রম বদলাতে লাইনগুলো উপরে-নিচে সরান।
- আলাদা লোগো দিতে চাইলে ছবিটা এই ফোল্ডারে রাখুন, তারপর লাইনে `logo: 'expense.png'` যোগ করুন। না দিলে SCS লোগো দেখাবে।
- বদলানোর পর `sw.js`-এর `VERSION = 1` সংখ্যাটা ১ বাড়ান (2, 3 …)। তারপর ফাইলগুলো আবার হোস্টিংয়ে আপলোড করুন।

অ্যাপের ভিতর থেকে লিংক যোগ বা বদলানোর কোনো ব্যবস্থা নেই।

## প্রতিটি Apps Script অ্যাপে যা লাগবে
SCS SUIT-এর ভিতরে খোলার জন্য প্রতিটি অ্যাপের `doGet`-এ এই লাইনটা থাকতে হবে:
```
.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)
```
এছাড়া Deploy-এ "Who has access" হতে হবে **Anyone**। কোনো অ্যাপ সাদা বা ফাঁকা দেখালে সাধারণত এই দুটোর একটা নেই। 

## হোস্টিং (ফ্রি)
- **Netlify Drop:** app.netlify.com/drop খুলে পুরো `scs-suit` ফোল্ডারটা টেনে ছেড়ে দিন।
- **GitHub Pages:** নতুন repository-তে ফাইলগুলো আপলোড করুন, তারপর Settings › Pages চালু করুন।

## ইনস্টল
- **Android (Chrome):** লিংকটা খুলে "📲 SCS SUIT ইনস্টল করুন" চাপুন, অথবা মেনু › Install app।
- **iPhone / iPad (Safari):** লিংকটা খুলে Share (□↑) › Add to Home Screen চাপুন।
- **Windows / Mac (Chrome বা Edge):** ঠিকানা-বারের ইনস্টল আইকন চাপুন।
- **Mac (Safari 17 বা নতুন):** File › Add to Dock।

## ব্যবহার
- **হোম পেজ:** শুধু অ্যাপের নাম ও লোগো থাকে, আর উপরে একটা সরু বারে রিফ্রেশ বাটন।
- **অ্যাপ খুললে:** পুরো স্ক্রিন অ্যাপের জন্য থাকে। উপরের মাঝখানে একটা ছোট ভাসমান বোতাম থাকে: **‹** চাপলে সব অ্যাপে ফেরা যায়, **⟳** চাপলে অ্যাপটা রিফ্রেশ হয়।
- **বোতাম সরানো:** বাম পাশের **⋮** ধরে টেনে বোতামটা যেকোনো জায়গায় সরানো যায়, জায়গাটা মনে থাকে। ⋮-তে ডাবল-ক্লিক করলে বোতাম আবার মাঝখানে ফিরে যায়।
- **কম্পিউটারে:** ইনস্টল করা অ্যাপের টাইটেল বারে ছোট **˄** চিহ্ন চাপলে টাইটেল বার লুকিয়ে যায়। তখন ছোট বোতামটা টাইটেল বারের জায়গাতেই বসে, ফলে স্ক্রিনে আরো জায়গা পাওয়া যায়।
- **রিফ্রেশ:** স্ক্রিন টেনে নামালে রিফ্রেশ হয় না।
- **দ্রুত বদল:** শেষ ৪টা খোলা অ্যাপ চালু থাকে, তাই এক অ্যাপ থেকে আরেকটায় গেলে আবার লোড হয় না।
